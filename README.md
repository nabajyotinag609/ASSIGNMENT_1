# A Personalized Greeting


## 📌 Description
This Python program takes a user's **first name** and **last name** as input, combines them into a **full name**, and displays a greeting message using the full name.
It is demonstrating basic concepts such as user input, string concatenation, and formatted output.

## ⚙️ How the Program Works
1. The program prompts the user to enter their **first name**.
2. It then asks for the **last name**.
3. Both inputs are concatenated with a space in between to form the **full name**.
4. A greeting message is printed using the full name.

---

## 🧾 Code Functionality Breakdown

* `input()` → Takes user input from the keyboard.
* String concatenation (`+`) → Nabajyoti first name and Nag last name.
* `print()` → Displays a formatted greeting message.
* `sep=""` → Ensures no extra spaces are added in the output.

---

## ▶️ Sample Input

```
Enter your First name: Nabajyoti
Enter your Last name: Nag
```

## ▶️ Sample Output
'''
Hello, Nabajyoti Nag! Welcome to the my project.
'''
